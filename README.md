# 「***」 강의 소개 사이트 — 사용 · 관리 · 배포 안내

고려대학교 **학과 「***」 교과목을 소개하는 정적 웹사이트입니다.
서버 없이 `index.html` 을 더블클릭하면 바로 열리고, 파일을 그대로 웹에 올리면 배포가 끝납니다.

---

## 1. 폴더 구성

| 파일 | 하는 일 | 고칠 일 |
|---|---|---|
| `index.html` | 페이지 뼈대 | 거의 없음 |
| `config.js` | **사이트의 모든 내용** (문구·일정·과제·공지·FAQ·교수자·관리자 비밀번호 해시) | ✅ 여기만 고치면 됩니다 |
| `css/style.css` | 디자인 (맨 위 `:root` 에서 색상 변경) | 색을 바꾸고 싶을 때 |
| `js/main.js` | 소개·커리큘럼·달력·공지 화면 그리기 | 없음 |
| `js/interact.js` | 투표·수강 신청·로그인·출석·과제 제출·팝업·폭죽 | 없음 |
| `js/admin.js` | 관리자 화면 | 없음 |
| `js/store.js` | 데이터 저장소 (지금은 브라우저 저장소 사용) | 서버를 붙일 때 |

> 사진을 쓰려면 `images/` 폴더를 만들어 사진을 넣고, 관리자 화면(또는 `config.js`)의 교수자 → 사진 경로에 `images/파일이름.jpg` 를 적으세요.

## 2. 방문자(수강생)가 쓰는 기능

- **상단 메뉴**: 프로그램 소개 · 커리큘럼 · 참여하기 · 수강 안내 · FAQ · 교수자로 이동. 휴대폰에서는 ☰ 버튼.
- **공지사항**: 첫 화면 아래. 중요 공지가 맨 위에 고정되고, 눌러서 내용을 펼칩니다.
- **커리큘럼**: 주차를 누르면 날짜·시간·장소·학습 내용·참고 영상·과제(마감까지 남은 시간)가 펼쳐집니다.
- **월간 달력**: 매주 수업일이 자동 표시. 날짜를 누르면 그날 수업 내용이 나옵니다.
- **참여하기**: 배우고 싶은 주제 투표(막대그래프), 수강 신청서 작성(빠진 항목 안내).
- **수강생 공간**: 학번·이름으로 로그인 → 출석 체크, 과제 파일 제출, 나의 출석률·제출 현황.
- **안내 팝업**: 처음 들어오면 잠시 뒤 수강 신청 안내. "오늘 하루 보지 않기" 가능.
- **첫 방문 폭죽**: 처음 방문했을 때 한 번만.

## 3. 관리자 모드

### 들어가기
1. 오른쪽 위 **🔒 자물쇠** 버튼을 누릅니다.
2. 관리자 비밀번호를 입력합니다. **처음 비밀번호: `sakura2026!`**
3. ⚠️ **처음 들어가면 반드시 비밀번호부터 바꾸세요** (아래 ‘비밀번호 변경’).

비밀번호는 `config.js` 에 원문이 아닌 **해시값**(소금을 친 SHA-256을 20,000번 반복)으로만 저장됩니다.
5번 틀리면 30초 동안 잠깁니다. 관리자 상태는 브라우저 탭을 닫으면 풀립니다.

### 관리자 메뉴

| 메뉴 | 할 수 있는 일 |
|---|---|
| 📊 대시보드 | 명단·신청서·출석·과제·투표·공지 수 한눈에 보기, 설정 상태 확인 |
| 📢 공지 관리 | 새 공지 올리기(중요 공지 고정), 기존 공지 수정·순서 변경·삭제 |
| ✏️ 사이트 편집 | 기본 정보·메뉴·첫 화면·소개·커리큘럼(주차·과제·휴강일)·투표·신청서 항목·팝업·수강 안내·FAQ·교수자 등 **모든 내용을 입력 칸으로 수정** |
| 👥 수강생 명단 | 한 명씩 등록, 엑셀에서 복사해 붙여 넣기 / CSV 파일로 한꺼번에 등록, 신청자를 명단으로 가져오기, 검색, 삭제, 엑셀로 내려받기 |
| 🗓️ 출석 현황 | 수강생 × 주차 출석부, 칸을 눌러 출석/결석 직접 수정(공결 처리), 엑셀로 내려받기 |
| 📝 과제 현황 | 과제별 제출/지각/미제출과 제출 시각, 엑셀로 내려받기 |
| 📮 수강 신청 | 제출된 신청서 전체 보기·삭제, 엑셀로 내려받기 |
| 💾 설정 파일 | `config.js` 로 저장, 저장한 파일 불러오기, 원본으로 되돌리기, 수강생 데이터 백업·복원 |
| 🔑 비밀번호 | 비밀번호 변경 (새 해시값 생성) |

### 내용을 고치고 모두에게 반영하는 순서 ⭐
1. **사이트 편집** 또는 **공지 관리**에서 내용을 고칩니다.
2. 아래쪽 **‘적용하고 미리보기’** → 이 브라우저에서 바뀐 사이트를 확인합니다.
   (이때 왼쪽 아래에 "⚙️ 관리자 수정본 적용 중" 표시가 보입니다 — 아직 **나에게만** 보이는 상태)
3. **설정 파일 → ‘config.js 내려받기’**.
4. 내려받은 `config.js` 로 사이트 폴더의 `config.js` 를 **교체**하고 다시 배포(아래 5장)합니다.
5. 배포 후 **설정 파일 → ‘원본으로 되돌리기’**를 누르면 관리자 브라우저도 배포된 파일 기준으로 돌아갑니다.

> 관리자 화면에서 저장한 `config.js` 에는 원래 파일의 설명 주석이 빠집니다. 항목 설명은 이 문서와 관리자 편집 화면의 이름표를 참고하세요.

### 엑셀 파일
모든 ‘엑셀로 내려받기’는 **CSV(UTF-8)** 파일입니다. 엑셀에서 더블클릭하면 한글이 깨지지 않고 열립니다.
수강생 명단을 엑셀에서 만들 때는 `학번, 이름, 학과, 이메일` 순서로 열을 두고 **CSV**로 저장해 불러오면 됩니다
(엑셀 기본 형식인 CP949 CSV도 읽을 수 있습니다). 엑셀 표를 그대로 복사해 붙여 넣어도 됩니다.

### 명단으로 로그인 제한하기
사이트 편집 → 수강생 공간 → **로그인 허용 기준**
- `누구나 로그인` (기본) · `신청서 낸 학번만` · `수강생 명단에 있는 학번·이름만`

### 출석 체크 시간
사이트 편집 → 수강생 공간 → 출석 규칙
- **언제든 출석 허용(테스트용)** 이 켜져 있으면 지난 수업도 출석 체크가 됩니다. **실제 운영 전 반드시 끄세요.**
- 끄면 수업 당일, 시작 10분 전 ~ 시작 30분 후에만 출석 버튼이 열립니다(분 단위 조정 가능).

## 4. ⚠️ 꼭 알아야 할 한계 (데모 모드)

이 사이트는 **서버가 없는 정적 사이트**입니다. 그래서:

- 수강생 데이터(신청서·출석·과제·투표·명단)는 **각자의 브라우저에만** 저장됩니다.
  수강생 A가 낸 신청서는 교수자의 관리자 화면에 **나타나지 않습니다.** 관리자 화면에는 *그 브라우저에 저장된 기록만* 보입니다.
- 과제 파일은 **실제로 업로드되지 않고** 파일 이름·크기·제출 시각만 기록됩니다.
- 투표의 ‘실시간’은 같은 브라우저의 여러 탭 사이에서만 동작합니다.
- 관리자 비밀번호는 원문을 숨겼지만, 브라우저 개발자 도구를 다룰 줄 아는 사람까지 막는 보안은 아닙니다.
  **성적 등 민감한 정보를 관리하는 용도로는 쓰지 마세요.**

→ 실제 수업에서 여러 학생의 기록을 한곳에 모으려면 **서버 연결**이 필요합니다.
`js/store.js` 의 함수들(투표·신청·로그인·출석·과제·명단)만 같은 이름으로 다시 구현하면 화면 코드는 그대로 쓸 수 있도록 만들어 두었습니다.
추천: **Firebase**(Firestore + Authentication + Storage) 또는 **Supabase**. 이때 관리자 비밀번호도 서버 로그인으로 바꾸는 것이 안전합니다.

> 서버 없이 지금 할 수 있는 대안: 수강 신청·과제 제출은 **구글 설문지 / LMS(블랙보드) 링크**로 받고,
> 이 사이트는 소개·일정·공지 용도로 쓰는 방법도 있습니다.

## 5. 배포 방법 (모두 무료)

배포할 것은 **폴더 전체**(`index.html`, `config.js`, `css/`, `js/`, 있다면 `images/`)입니다. 빌드 과정은 없습니다.

### A. Netlify Drop — 가장 쉬움 (1분)
1. https://app.netlify.com/drop 접속 (무료 가입)
2. 사이트 폴더를 브라우저 창으로 **끌어다 놓기**
3. `https://임의이름.netlify.app` 주소가 바로 생깁니다. 사이트 설정에서 이름 변경 가능.
4. 내용을 바꾼 뒤에는 Deploys 화면에 폴더를 다시 끌어다 놓으면 됩니다.

### B. GitHub Pages
1. GitHub 에 새 저장소(public)를 만들고 폴더의 파일을 모두 올립니다 (`Add file → Upload files`).
2. 저장소 **Settings → Pages → Branch: `main` / `(root)`** → Save.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다.
4. 수정할 때는 `config.js` 만 다시 올리면 됩니다.

### C. 학교·학과 웹 서버
학과 홈페이지 관리자에게 폴더를 전달해 원하는 경로에 그대로 올려 달라고 하면 됩니다. 별도 설정이 필요 없습니다.

### D. 그냥 파일로 공유
폴더를 압축해 보내면 받은 사람이 `index.html` 을 더블클릭해서 볼 수 있습니다 (인터넷 연결 시 글꼴까지 정상 표시).

### 배포 전 체크리스트
- [ ] 관리자 비밀번호 변경 후 저장한 `config.js` 로 교체했나요?
- [ ] `**학과`, `***`, `○○관`, 홍길동, 이메일·전화번호 등 **임시 값**을 실제 정보로 바꿨나요?
- [ ] 출석 규칙의 **‘언제든 출석 허용’** 을 껐나요?
- [ ] 수업 시작일·휴강일·과제 마감일이 맞나요? (커리큘럼·달력·카운트다운이 모두 이 값으로 계산됩니다)
- [ ] 참고 영상 링크(지금은 유튜브 검색 링크)를 실제 영상으로 바꿨나요?
- [ ] 팝업 문구(정원 등)를 실제 정보로 바꿨나요?

## 6. 자주 하는 작업

| 하고 싶은 일 | 방법 |
|---|---|
| 개강일 변경 | 사이트 편집 → 커리큘럼·일정 → 수업 일정 → 1주차 날짜 (이후 주차 자동 계산) |
| 휴강 추가 | 같은 곳 → 휴강일 → + 추가 (그 주는 건너뛰고 일정이 한 주씩 밀림) |
| 과제 추가 | 커리큘럼 → 주차 → 해당 주 펼치기 → ‘+ 과제 추가’ |
| 공지 올리기 | 공지 관리 → 새 공지 올리기 → 적용 → 설정 파일 저장·교체 |
| 팝업 끄기 | 사이트 편집 → 안내 팝업 → ‘팝업 사용’ 체크 해제 |
| 색상 바꾸기 | `css/style.css` 맨 위 `:root` 의 `--pink-*`, `--purple-*` 값 |
| 투표 결과 초기화 | (데모 모드) 브라우저 사이트 데이터 삭제 |
